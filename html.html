HTML & CSS

HTML wurde 1991 von Tim Berners-Lee entwickelt, um Webseiten im Internet zu strukturieren. CSS wurde 1996 eingeführt, um Layout und Design von Webseiten unabhängig vom Inhalt zu gestalten. Seitdem bilden HTML und CSS die Grundlage des modernen Webs und haben sich kontinuierlich weiterentwickelt, um neue Features und Designmöglichkeiten zu bieten.

Mit HTML & CSS lassen sich Inhalte semantisch strukturieren, multimediale Elemente einbinden, Formulare erstellen und interaktive Webseiten gestalten. Dieses Kapitel zeigt praktisch alle wichtigen Features und Techniken, die Entwickler heute verwenden können.
